The following folder has a jupyter noteobook in which you can determine the distances between coordinates given in the gef file. It loads them all 
in and in this case also tells you when they are within a radius of 4 m of a borehole and if it is more than 1. This was done to see whether 
there were boreholes that had CPT around them done before and after. Otherwise at distances greater than 4 m and with only one CPT it would be very 
difficult to determine if changes are visible. 

The CPT which are compared are stored in the folders for the location. They are marked with 'Bxx' which is the borehole ID on that location. Then 
comes the ID for the CPT everything before "vs" is for before the borehole was drilled and all ids after the vs is for after the borehole was drilled.
